Features

30+ dedicated parsers
git, cargo, npm, docker, gh, pytest, jest, eslint, ruff, biome, and more. Each parser understands the command's output format.
6 output formats
Compact, JSON, CSV, TSV, Agent, Raw. Every command supports all formats via --json, --csv, etc.
JSON query engine
Built-in jq-lite with trs json -q '.users[].name'. No dependency on jq.
Intelligent file reader
trs read -l aggressive extracts only function signatures (93% reduction). Minimal mode strips comments.
Search & replace
Ripgrep-powered trs search and trs replace --dry-run. Compact output grouped by file.
AI tool hooks & rules
trs init --all installs hooks in Claude Code, Gemini CLI, Cursor, OpenCode, Kilo, Factory Droid (programmatic) and drops rules files for Codex, Antigravity, Windsurf. Smart-merge into existing settings.json — user config preserved.
Fast find
trs find --gitignore uses a built-in walker respecting .gitignore. 5ms vs 280ms on large repos.
Generic compression
Commands without a parser still get ANSI stripping, whitespace collapse, and repeated-line dedup. ~30-40% free.
Built-in benchmark
trs benchmark git status measures compression ratio, token savings, and execution time per command.
Project digest (trs ingest)
LLM-ready index of any codebase. Budget-aware (--budget 128k), git-aware (--since-last, --fresh), dependency graph (--deps), stale detection in --list, Ollama post-processing. Output: path on stdout, digest on disk.
Chain-aware rewrite
cd X && git status or cargo fmt && cargo clippy get each rewritable segment wrapped with trs. Pipes and semicolons pass through untouched.
Token savings dashboard
trs stats shows cumulative compression across all tracked commands, period range, tokens saved per day. JSON output for dashboards.

Install

universal (macOS / Linux)
curl -fsSL https://raw.githubusercontent.com/dPeluChe/trs/main/scripts/install.sh | sh
Windows (PowerShell)
irm https://raw.githubusercontent.com/dPeluChe/trs/main/scripts/install.ps1 | iex
npm (cross-platform)
npm install -g @dpeluche/trs
from source (Rust toolchain)
cargo install tars-cli
pre-built binaries
github.com/dPeluChe/trs/releases

The install script and npm package ship the same Rust binary. Shell launcher on Unix means zero Node overhead at runtime.
