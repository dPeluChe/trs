## Decisions

### Import resolution strategy
Unified `resolve_imports` router dispatches based on import shape:
- `./`/`../`/`@/` → `resolve_relative` (path normalization or suffix match)
- Contains `/` → `resolve_module_path` (last 2 then 1 components)
- Plain name → `resolve_by_stem` (stem index lookup)
Discarded: full module-path parsing (too language-specific), AST-based extraction (too slow).

### Go test error message buffering
Go test `-v` outputs error lines BEFORE `--- FAIL:`, not after. Initial design collected errors
after the FAIL marker. Fixed by buffering lines between `=== RUN` and the result line.

### Docs project detection
Projects with >50% `.md`/`.txt` files are classified as docs/skills — dep summary is suppressed
(no source imports to detect, header would be empty noise).
